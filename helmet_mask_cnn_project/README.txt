# CNN Helmet/Mask Classifier

This project uses a Convolutional Neural Network (CNN) to classify an image into:
- `with_helmet_mask`
- `without_helmet_mask`

## Important
The folders are empty. Add your own real, correctly labelled images before training.
Do not report an accuracy value until you have run the model on a separate test set.

## 1. Install
Open a terminal in this project folder and run:

```bash
python -m venv venv
```

Windows:
```bash
venv\\Scripts\\activate
```

Then:
```bash
pip install -r requirements.txt
```

## 2. Add images
Place images into these folders:

```text
dataset/
  train/
    with_helmet_mask/
    without_helmet_mask/
  validation/
    with_helmet_mask/
    without_helmet_mask/
  test/
    with_helmet_mask/
    without_helmet_mask/
```

Use a variety of people, backgrounds, lighting and camera angles. Keep the test images separate from the training images. Aim for a balanced number of images in each class. A reasonable classroom demonstration could start with 100+ images per class, split approximately 70% train, 15% validation and 15% test.

**Label definition:** This starter treats “helmet/mask” as one combined positive class. If your instructor expects helmet detection and mask detection as separate tasks, make four classes or build two separate binary classifiers instead.

## 3. Train
```bash
python train.py
```

The script:
- resizes images to 128 x 128;
- normalizes pixels to 0–1;
- applies convolution, ReLU and max pooling;
- trains a dense binary classifier;
- saves the model and plots;
- reports test accuracy, classification report and confusion matrix.

Files created after training:
- `helmet_mask_cnn.keras`
- `accuracy_curve.png`
- `loss_curve.png`
- `results.txt`

## 4. Predict a new image
```bash
python predict.py path/to/your/image.jpg
```

## CNN flow for your video
Original image → Kernel/filter → Convolution → Feature map → ReLU → Pooling → Classification

## Limitation
This is an educational prototype. It is not suitable for safety enforcement or real-world compliance decisions without a larger, carefully evaluated dataset.
